# Solvery Slots Sync

Chrome extension для ручной синхронизации доступных слотов из Google Calendar в календарь наставника на Solvery.

Расширение читает события из календаря `Solvery Slots`, показывает `Preview`, а затем по кнопке `Sync now` добавляет недостающие слоты на платформу через интерфейс Solvery.

## Что умеет

- берет события из Google Calendar
- работает с календарем `Solvery Slots`
- использует название события `Solvery Slots` как маркер слота
- синхронизирует диапазон `сейчас + 30 дней`
- игнорирует all-day события
- игнорирует recurring события
- пропускает дубли, если слот уже существует в Solvery
- поддерживает `Preview` перед синком

## Как это работает

1. Вы создаете событие в Google Calendar.
2. Событие должно быть в календаре `Solvery Slots`.
3. Название события должно быть `Solvery Slots`.
4. Расширение находит такие события и превращает их в слоты.
5. На странице Solvery расширение открывает форму добавления слота.
6. Заполняет:
   - `Date`
   - `Time start`
   - `Time end`
7. Нажимает `Сохранить`.

## Установка

1. Склонируйте репозиторий.
2. Откройте `chrome://extensions` или страницу расширений в Arc.
3. Включите `Developer mode`.
4. Нажмите `Load unpacked`.
5. Выберите папку проекта.

## Настройка Google OAuth

Нужен собственный `Google OAuth Client ID`.

### 1. Создайте проект в Google Cloud

- Откройте [Google Cloud Console](https://console.cloud.google.com/)
- Создайте новый проект или выберите существующий

### 2. Включите Google Calendar API

- Перейдите в `APIs & Services`
- Откройте библиотеку API
- Включите `Google Calendar API`

### 3. Настройте OAuth consent screen

- Откройте `Google Auth Platform` или `OAuth consent screen`
- Укажите имя приложения и email
- Если приложение в test mode, добавьте свой Google email в `Test users`

### 4. Создайте OAuth Client ID

- Создайте `OAuth Client ID`
- Используйте тип, подходящий для OAuth redirect URI с `chromiumapp.org`
- В `Authorized redirect URIs` добавьте redirect URI из встроенного раздела `Settings` в popup расширения

Пример redirect URI:

```text
https://<extension-id>.chromiumapp.org/oauth2
```

### 5. Укажите Client ID в расширении

1. Откройте popup расширения
2. Откройте `Settings`
3. Вставьте `Google OAuth Client ID`
4. Нажмите `Save settings`

## Использование

1. Откройте страницу календаря наставника в Solvery.
2. Убедитесь, что вы залогинены.
3. Откройте popup расширения.
4. При необходимости откройте `Settings` и проверьте настройки.
5. Нажмите `Connect Google`.
6. Нажмите `Preview`.
7. Проверьте список слотов, которые будут созданы.
8. Нажмите `Sync now`.

## Правила для событий

Событие будет считаться слотом, если:

- оно находится в календаре `Solvery Slots`
- его название равно `Solvery Slots`
- у него есть точное время начала и конца
- оно не является all-day событием
- оно не является recurring событием

## Что синхронизируется

Для каждого события расширение переносит:

- дату
- время начала
- время окончания
- таймзону календаря

Описание, участники и другие поля не используются.

## Ограничения текущей версии

- запуск только вручную через `Sync now`
- синк только в одну сторону: `Google Calendar -> Solvery`
- удаление слотов из Solvery не поддерживается
- обновление уже существующих слотов не поддерживается
- логика привязана к текущему DOM Solvery и `calndr.pro`

## Privacy

Расширение работает локально в браузере пользователя.

Что читает расширение:

- события из Google Calendar
- страницу календаря наставника в Solvery
- iframe `calndr.pro`, в котором создаются слоты

Что делает расширение:

- читает события из календаря `Solvery Slots`
- сравнивает их с уже существующими слотами в Solvery
- по кнопке пользователя создает недостающие слоты

Что расширение не делает:

- не отправляет данные на собственный сервер
- не использует стороннюю аналитику
- не хранит данные вне браузера пользователя

Что хранится локально:

- настройки расширения в `chrome.storage.local`
- OAuth token Google и служебное состояние sync только в `chrome.storage.session`

Это значит:

- токен и runtime-состояние не сохраняются между сессиями браузера
- после закрытия браузера Google нужно будет подключить заново

## Структура проекта

- `manifest.json` — конфигурация расширения
- `background.js` — OAuth, Google Calendar API, orchestration sync
- `popup.html` / `popup.js` / `popup.css` — интерфейс расширения и встроенные настройки
- `content/solvery-page.js` — работа со страницей Solvery
- `content/calndr-frame.js` — работа с iframe `calndr.pro`
